## How I Approach AI Products

1. **Embed into real action flows:** AI outputs should drive the next concrete user step rather than sitting isolated in a chat box.
2. **Manage probability with clear boundaries:** Models are inherently probabilistic—preconditions, state visibility, and graceful fallback belong in the core flow.
3. **Close the loop with evaluation:** Pair behavior logs and scenario golden sets with firsthand product usage to steer iterations.

## Areas of Focus

- **B2B Agents & Skills:** Tool calling, domain skill packaging, cross-app context handoff
- **RAG & Evaluation:** Knowledge governance, permission boundaries, reranking, retrieval evals
- **Human-AI Interaction:** GUI × CLI convergence, incremental prototyping, living specs
