## 我怎么判断一个 AI 产品

1. **是否顺着业务流推动真实动作**：结果要自然嵌入用户的下一步工作，而不是停留在孤立生成。
2. **概率波动下边界是否可控**：承认大模型天然是概率性的，把前置条件、状态感知和兜底恢复放进主流程。
3. **有没有数据与场景评测闭环**：用真实行为日志和场景黄金测试集校准迭代方向，用真实体感和反馈修正假设。
